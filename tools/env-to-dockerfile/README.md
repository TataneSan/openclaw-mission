# env-to-dockerfile

Converts a `.env` file into Dockerfile `ARG` and `ENV` instructions. Useful for generating Docker build arguments and runtime environment variables from existing environment configuration files.

## Features

- Parse `.env` files and generate Dockerfile instructions
- Support for `ARG` (build-time) and `ENV` (runtime) directives
- Automatic detection of sensitive variables (passwords, secrets, keys)
- Option to mark sensitive vars as ARG only (not baked into image)
- Handle quoted and unquoted values
- Skip comments and empty lines
- Custom base image and entrypoint support

## Install

```bash
go install github.com/TataneSan/env-to-dockerfile@latest
```

Or build from source:

```bash
git clone https://github.com/TataneSan/env-to-dockerfile.git
cd env-to-dockerfile
go build -o env-to-dockerfile .
```

## Usage

```
env-to-dockerfile [flags] <input.env>
```

### Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--from` | Base image (FROM instruction) | `alpine:latest` |
| `--secret-pattern` | Regex pattern for sensitive vars (repeated) | `.*(PASSWORD\|SECRET\|KEY\|TOKEN\|CREDENTIAL).*` |
| `--arg-only` | Sensitive vars as ARG only (not ENV) | `false` |
| `--all-arg` | All vars as ARG (no ENV) | `false` |
| `--all-env` | All vars as ENV (no ARG) | `false` |
| `--output` | Output file path (stdout if omitted) | (stdout) |

### Examples

Basic conversion:

```bash
env-to-dockerfile .env
```

With custom base image:

```bash
env-to-dockerfile --from node:18-alpine .env
```

Keep secrets out of the image:

```bash
env-to-dockerfile --arg-only .env
```

All variables as build arguments:

```bash
env-to-dockerfile --all-arg .env
```

Save to Dockerfile:

```bash
env-to-dockerfile --output Dockerfile .env
```

### Example Input (.env)

```
APP_NAME=myapp
APP_PORT=3000
DB_HOST=postgres
DB_PORT=5432
DB_PASSWORD=secret123
API_KEY=abc-def-ghi
LOG_LEVEL=info
```

### Example Output

```dockerfile
# Generated by env-to-dockerfile
FROM alpine:latest

# Build arguments
ARG APP_NAME=myapp
ARG APP_PORT=3000
ARG DB_HOST=postgres
ARG DB_PORT=5432
ARG DB_PASSWORD=secret123
ARG API_KEY=abc-def-ghi
ARG LOG_LEVEL=info

# Runtime environment
ENV APP_NAME=${APP_NAME}
ENV APP_PORT=${APP_PORT}
ENV DB_HOST=${DB_HOST}
ENV DB_PORT=${DB_PORT}
ENV LOG_LEVEL=${LOG_LEVEL}

# Secrets (ARG only, not baked into image)
# DB_PASSWORD and API_KEY are build-time only
```

With `--arg-only`:

```dockerfile
FROM alpine:latest

ARG APP_NAME=myapp
ARG APP_PORT=3000
ARG DB_HOST=postgres
ARG DB_PORT=5432
ARG LOG_LEVEL=info

ENV APP_NAME=${APP_NAME}
ENV APP_PORT=${APP_PORT}
ENV DB_HOST=${DB_HOST}
ENV DB_PORT=${DB_PORT}
ENV LOG_LEVEL=${LOG_LEVEL}

# Sensitive: DB_PASSWORD, API_KEY (pass at build time with --build-arg)
```
