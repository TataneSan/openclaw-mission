# env-to-script

Convert `.env` files to executable shell scripts with proper quoting and escaping.

Supports **sh**, **bash**, **zsh**, **fish**, and **PowerShell** output formats.

## Install

```bash
go install github.com/TataneSan/env-to-script@latest
```

Or build from source:

```bash
git clone https://github.com/TataneSan/env-to-script.git
cd env-to-script
go build -o env-to-script .
```

## Usage

```
env-to-script [flags] .env
```

### Flags

| Flag | Default | Description |
|------|---------|-------------|
| `-f` | *(required)* | Path to the .env file |
| `-o` | stdout | Output file path (written with 755 permissions) |
| `-t` | `sh` | Script type: `sh`, `bash`, `zsh`, `fish`, `powershell` |
| `-export` | `true` | Prefix variables with `export` (sh/bash/zsh only) |
| `-single` | `false` | Use single quotes instead of double quotes |
| `-escape` | `true` | Escape `$` signs in values |
| `-j` | `false` | Output as JSON instead of shell script |

## Examples

### Generate a bash script

```bash
env-to-script -f .env -t bash -o setup.sh
source setup.sh
```

### Generate a fish script

```bash
env-to-script -f .env -t fish
```

Output:
```fish
#!/usr/bin/env fish
# Auto-generated by env-to-script
# Source: .env

set -gx DB_HOST "localhost"
set -gx DB_PORT "5432"
set -gx API_KEY "my-secret-key"
```

### Generate a PowerShell script

```bash
env-to-script -f .env -t powershell -o setup.ps1
```

Output:
```powershell
# Auto-generated by env-to-script
# Source: .env
#Requires -Version 5.1

Set-Item -Path env:DB_HOST -Value 'localhost'
Set-Item -Path env:DB_PORT -Value '5432'
```

### Output as JSON

```bash
env-to-script -j .env
```

Output:
```json
[
  {"Key": "DB_HOST", "Value": "localhost"},
  {"Key": "DB_PORT", "Value": "5432"}
]
```

### Use single quotes (no variable expansion)

```bash
env-to-script -f .env -t bash -single
```

This is useful when values contain `$` or backticks that should not be interpreted.

## Input format

The tool reads standard `.env` format:

```
KEY=value
KEY="quoted value"
KEY='single quoted'
export KEY=value
# comments are ignored
```

- Lines starting with `#` are skipped
- Empty lines are skipped
- Leading `export` is stripped
- Surrounding quotes are removed
- Keys must be valid shell variable names (letters, digits, underscore; must start with letter or underscore)
